## Getting started

> **Prerequisites:**
> The following steps require [NodeJS](https://nodejs.org/en/) to be installed on your system.

Install the dependencies:

```
npm install
```

Run a development version of the Next.js app with:

```
npm run dev
```

After a few seconds, your project should be accessible at
[http://localhost:3000/](http://localhost:3000/)

Create an optimized production build with:

```
npm run build
```

## Netlify deployment

The repository already includes `netlify.toml` pointing Netlify at the Next.js build output and enabling the official Next.js plugin:

```
[build]
  command = "npm run build"
  publish = ".next"

[[plugins]]
  package = "@netlify/plugin-nextjs"
```

When deploying on Netlify, ensure the site uses a Node.js version compatible with Next.js 14 (Node 18+), and that `npm install` completes successfully so the `next` binary is available for the build step.
